# CasaLoom Shop All visual update

Updated only the Shop All page presentation:
- Hero now uses up to six live product images (three on each side).
- Added floral decorations and leafy accents around the hero.
- Restored the left editorial "Handpicked for your home" panel with three product thumbnails.
- Product grid shows five compact cards per row on wide desktop screens and adapts down for smaller screens.
- Existing product data, filtering, category selection, wishlist, product links and order actions remain connected to the existing components.

No database migrations or backend changes are included in this visual update.

The `.env` file is intentionally excluded from the ZIP for credential safety. Keep your existing local `.env` file when replacing project files.
