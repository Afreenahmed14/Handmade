# CasaLoom Customer Pages V24

- Notifications now use the same compact blush/floral visual language as My Orders.
- Notification cards are shorter with smaller icons, text, dates, and read controls.
- Wishlist now uses the same compact customer-page shell and floral background.
- Wishlist product cards are smaller, square-image cards with compact product details and actions.
- Existing data fetching, read-state updates, wishlist refresh, removal, and move-to-cart behavior are unchanged.
- No Supabase schema or environment changes are required.
